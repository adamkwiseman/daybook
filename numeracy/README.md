# Number Sense Check-in

Interactive cho and KO numeracy assessments.

- [cho assessment](https://adamkwiseman.github.io/daybook/numeracy/?grade=2)
- [KO assessment](https://adamkwiseman.github.io/daybook/numeracy/?grade=3)

Each assessment has a 30-minute limit. Students use teacher-issued anonymous codes. Listen buttons play approved American voice recordings. Scores are calculated and saved by the dedicated Supabase numeracy service.

Student codes, answer keys, and private database credentials are not included in this folder.

## Continuing missing questions

Students in either group can enter their existing code and choose **Continue missing questions**. This combines saved work from earlier attempts, keeps the earliest completed answer for each question (including incorrect answers), and opens only incomplete questions with 30 additional minutes. Partially entered answers are prefilled. Original attempts remain available; the continuation saves a new combined result. Teachers should use the latest completed continuation for the combined report.

**Skip practice** is available on the entry screen and during tool practice. It leads to the ready screen; the timer starts only when the student starts the assessment. Continuation skips tool practice automatically.

The private assessment service enforces carried-answer protection and calculates scores. Its source and answer key must not be uploaded to this public repository.
