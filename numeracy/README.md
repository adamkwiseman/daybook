# Number Sense Check-in

Interactive cho and KO numeracy assessments.

- [cho assessment](https://adamkwiseman.github.io/daybook/numeracy/?grade=2)
- [KO assessment](https://adamkwiseman.github.io/daybook/numeracy/?grade=3)

Each assessment has a 30-minute limit. Students use teacher-issued anonymous codes. Listen buttons play approved American voice recordings. Scores are calculated and saved by the dedicated Supabase numeracy service.

Student codes, answer keys, and private database credentials are not included in this folder.
